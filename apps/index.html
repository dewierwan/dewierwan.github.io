Apps I use

The Mac apps and Chrome extensions I use most, and what each one is for.

Mac apps

  • Raycast: It’s the fastest way to open an app or write a common piece of text (e.g. I use .dwem and it outputs my work email). It also remembers everything I copy, so I don’t lose things I pasted an hour ago.
  • Copy Path: A Raycast add-on that copies the link of the web page I’m on. I set it to Command-Shift-C, so I never have to click into the address bar to grab a link.
  • Ghostty: I use this to run Claude Code and Codex.
  • Granola: It takes notes in meetings so I don’t have to. It listens to the call, then writes up what was said.
  • Beeper: It puts my WhatsApp, Signal and LinkedIn messages in one app, so I don’t have to check three.
  • Cold Turkey Blocker: It blocks distracting websites and apps at times I set in advance, so I’m forced to stop using my laptop.
  • Keep Awake: I made this. It stops my Mac from going to sleep for a set time. It’s useful when I want the laptop to keep running when I close the lid, e.g. if I’m running a bunch of agents and I close the laptop to travel somewhere.
  • CleanShot X: It makes it super fast to take screenshots or screen recordings, and edit them before sharing with others.
  • Thaw: This cleans up the menu bar on my MacBook, and enables me to have a priority ranking over which menu bar items I want to see and when.
  • Reflex: Makes the play, pause and skip keys on my keyboard control Spotify. Without it, they open Apple Music, which nobody wants.

Chrome extensions

  • Paste Into: I made this. When you copy text from one app and paste it into another, the formatting often breaks. Paste Into fixes it, so text from Notion or Claude looks right in Gmail, Slack or Google Docs.
  • Claude in Chrome: Lets Claude use websites for me. It can read the page I’m on, click buttons and fill in forms.
  • Simplify Gmail: Hides the clutter in Gmail, so the screen shows little more than my emails.
  • uBlock Origin Lite: Blocks ads, and stops companies from tracking what I do online.
  • Dark Reader: Turns bright white websites dark, which is important when working at night!
  • Wikiwand: Makes Wikipedia nicer to read, with a cleaner page layout.
  • Wayback Machine: When a web page has been deleted or changed, this finds a saved copy of how it used to look.
  • Everything Metric: Changes miles, pounds and Fahrenheit on any web page into kilometers, kilograms and Celsius, so I don’t have to convert them in my head. It’s about time we abolish Imperial.
